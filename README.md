# ED Note Vault

A simple searchable browser-based ED documentation template library.

## Features
- Search templates
- Filter by clinical category
- Click a template to expand/collapse
- Copy individual sections or the full note
- Light/dark mode
- Responsive desktop and mobile layout
- Allergy templates including urticaria and anaphylaxis

## Deployment
Upload `index.html`, `styles.css`, `data.js`, `app.js`, and `README.md` to the repository root and push to GitHub.

GitHub Pages may take a short time to redeploy after a push. The HTML uses versioned CSS/JS URLs to prevent browsers from mixing cached old files with new files.

## Disclaimer
Templates are starting points only. Edit every note to reflect the actual patient encounter, examination, investigations, local policy, and specialist advice. Do not enter patient-identifiable information into this tool.
